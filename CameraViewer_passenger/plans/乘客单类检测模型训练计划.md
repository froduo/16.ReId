# 乘客单类检测模型训练计划（HX-CCD23 / CameraViewer）

> 目标：用 `head image/` 人工裁剪的乘客人体框数据（尺寸不一），借助
> `12.ultralytics/ultralytics` 配套环境训练一个**单类 passenger** 检测模型，
> 训练 **200 代**，导出 ONNX + TensorRT engine 并部署到 CameraViewer，使其
> 加载路径与系统配置 `config.ini` 一致。

## 1. 关键事实（已核实）

| 项 | 结论 |
|---|---|
| 数据源 | [`head image/`](head%20image) 变尺寸乘客人体框裁剪，文件名前缀 `V#` 为身份 |
| 合成脚本 | [`datasets/build_yolo_person_canvas.py`](datasets/build_yolo_person_canvas.py)：变尺寸裁剪等比缩放后粘贴到 640x640 画布，**粘贴区域即 person bbox，cls=0** |
| 数据集 | [`datasets/person_canvas/`](datasets/person_canvas)：images/labels 的 train 4000 / val 600；[`data.yaml`](datasets/person_canvas/data.yaml) 现名 `person` |
| 训练环境 | venv `/media/froduo/4AE2C4D0E2C4C205/projects/ultralytics_venv`（ultralytics 8.4.48 / torch 2.6.0+cu124 / RTX 2060） |
| 范式脚本 | [`train_head.py`](datasets/head_1/train_head.py)、[`export_head.py`](datasets/head_1/export_head.py) |
| 程序约束 | [`PersonDetector`](CameraViewer/src/persondetector.cpp) 仅取 `class_id==0`；engine 加载失败自动回退同名 `.onnx`；单类 ONNX 输出 `1x5x8400` |
| 模型加载 | [`pickDetectorModelPath()`](CameraViewer/src/mainwindow.cpp:2594) 以配置 `ModelPath` 为准；构建复制规则见 [`CameraViewer.pro`](CameraViewer/CameraViewer.pro:93) |

## 2. 流程

```mermaid
graph LR
  A[head image 变尺寸裁剪] --> B[合成 640 画布 单类 passenger]
  B --> C[person_canvas train val 数据集]
  C --> D[train_person 200 代 yolo11n]
  D --> E[best.pt 评估 val 与真实帧]
  E --> F[导出 ONNX 1x5x8400]
  F --> G[trtexec 构建 engine fp16]
  G --> H[部署 model 与 config.ini 保持一致]
```

## 3. 交付物

- `datasets/train_person.py`、`datasets/export_person.py`（新增，复用 head 范式）
- 权重：`datasets/person_canvas/runs/passenger_yolo11n/weights/best.pt`
- 导出：`passenger_yolo11n.onnx`（`1x3x640x640 → 1x5x8400`）
- 引擎：`passenger_yolo11n_trt10_x86.engine`（TRT 10.3 / fp16）
- 部署：`CameraViewer/model/` 与 `build-CameraViewer-main-Desktop-Debug/model/`
- 配置：`config.ini` → `ModelPath=./model/passenger_yolo11n_trt10_x86.engine`、`ModelKind=person`、`Letterbox=true`
- 文档：更新 `datasets/README_模型交付.md`

## 4. 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| base model | `yolo11n.pt` | 与既往一致；训练环境目录内即有 |
| epochs | 200 | 用户指定 |
| imgsz | 640 | 与程序输入一致 |
| batch | 16 | RTX 2060 4~6G 显存可承载 |
| device | 0 | 单卡 GPU |
| classes | 1 = passenger | 仅一类，id=0 |
| patience | 50 | 200 代内早停保护 |

## 5. 验收标准

1. `best.pt` 在 val 集 mAP50 达标（合成 val 预期 >0.95）。
2. 真实整帧抽检（`save_images/clips`）：乘客召回明显优于旧 `yolo26n`，误检可控。
3. 程序日志出现 `YOLO model loaded [TensorRT]: .../passenger_yolo11n_trt10_x86.engine`。
4. `CameraViewer.pro` 的 `ENGINE_SOURCE` 与 `config.ini` 的 `ModelPath` 指向同一文件。

## 6. 回滚

保留旧 `yolo26n_trt10_x86.engine`；如需回滚，仅改 `config.ini` 的 `ModelPath` 即可。
